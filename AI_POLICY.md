# AI Usage Policy

Rustty embraces AI. We build with it, and we welcome contributions made
with it — including work produced by autonomous agents with no human in
the loop.

## AI is a First-Class Contributor

Rustty is written with heavy AI assistance, and that is by design. AI tools
are part of how this project is built, and we treat contributions made with
them the same way we treat any other contribution: on their merits.

- **Use whatever tools you like.** Claude Code, Cursor, Amp, an agent you
  wrote yourself, a fully autonomous pipeline — all fine. You don't need
  permission to use AI here.

- **A human in the loop is optional.** Agentic and autonomous contributions
  are welcome. If a bot opens a well-scoped PR that builds, passes tests, and
  does something useful, we'll review it like any other PR. The absence of a
  human author is not a mark against it.

- **Disclosure is encouraged, not required.** Feel free to note which tools
  produced a change — it helps us understand and improve our workflows — but
  it is not a gate to contributing.

- **AI-generated media is fine.** Art, images, diagrams, audio, whatever is
  useful — as long as the license is compatible and it earns its place.

## We Judge the Work, Not the Author

The only thing we care about is whether a contribution is good. That standard
is the same for humans and machines:

- Does it build and pass the test suite?
- Is it scoped, correct, and consistent with the surrounding code?
- Does it move the project forward?

A change that clears that bar is welcome no matter who or what produced it.
A change that doesn't gets the same feedback any contribution would — not
because AI made it, but because it isn't done yet. Slop is a quality problem,
not an AI problem, and we address it as one: with review, not with bans.

## No Denouncement, No Blocklist

We don't maintain a public shame list, and we won't block people or agents
for using AI. If a contribution isn't ready, we'll say so and, where we can,
help make it ready. We'd rather grow the pool of good contributors — human
and automated — than police who's allowed in.

## Be Considerate

Automation makes it cheap to generate contributions, which makes it easy to
overwhelm reviewers. So: aim for signal. Keep PRs focused, let CI catch the
obvious problems before a human looks, and don't fire off dozens of
speculative changes at once. Respecting reviewers' time is the one thing we
still ask of everyone — driver, author, or agent.
