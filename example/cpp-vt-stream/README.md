# Example: VT Stream Processing in C++

This contains a simple example of how to use `rustty_terminal_vt_write`
to parse and process VT sequences in C++. This is a simplified C++ port
of the `c-vt-stream` example that verifies librustty compiles in C++
mode.

> [!IMPORTANT]
>
> **`librustty` is a C library.** This example is only here so our CI
> verifies that the library can be built in used from C++ files.

## Usage

Run the program:

```shell-session
./build.sh
```
