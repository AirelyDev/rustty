rustty web_canvas — browser-freestanding wasm

Loads rustty_web_canvas.wasm (wasm32-unknown-unknown, pure Rust, ZERO wasi imports — only the env Canvas imports), wires the Canvas FFI to a real offscreen 2d canvas, then: creates a web_canvas font Face, renders glyphs into a texture Atlas, shapes a string with the Shaper, and runs a VT terminal roundtrip via the retained rustty_vt_c C-ABI.

Serve from the repo root (python3 -m http.server) and open /example/wasm-web-canvas/index.html — a fetch() of the .wasm needs http(s), not file://.
