--- A MEASUREMENT TRAP, recorded because it nearly became a false finding ---
The first pass used rustty's DEBUG build against ghostty's distro RELEASE build and
produced 54.04 / 54.03 / 65.51 seconds versus 0.55 / 0.40 / 0.40 — a ~135x gap that reads
like a catastrophic regression. It is entirely the build profile: the same binary built
`--release` lands at 0.40s. Never compare a debug rustty against a packaged ghostty; the
comparison is meaningless and alarming in equal measure.
